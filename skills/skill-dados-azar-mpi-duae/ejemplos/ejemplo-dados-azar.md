# Ejemplo — De una unidad `.md` a una Dinámica de Dados MPI-DUAE

## Unidad de entrada

```markdown
# Unidad 6: Briefing y proceso creativo
Programa: Diseño Gráfico — I semestre · 1 sesión de 90 min
## Resultado de aprendizaje
Interpreta un briefing y genera múltiples conceptos creativos antes de decidir.
## Contenidos
- Lectura del briefing (conceptual)
- Generación de ideas / divergencia (procedimental)
- Apertura a la crítica (actitudinal)
```

---

## Dinámica generada

```markdown
# Dinámica de Dados — "El Triple Dado del Concepto"

> Mecánica: dados de consignas (azar combinatorio) · Acondicionado al MPI-DUAE.

## 0. Síntesis
- **Tema:** briefing y proceso creativo.
- **RA:** interpretar briefing y generar múltiples conceptos antes de decidir.
- **Nivel · jugadores · duración:** Diseño I · equipos de 3 · 45 min.
- **Rol del azar:** combinar (creatividad) + sortear roles.

## 1. Objeto aleatorio y caras
Tres dados de consignas:
| Dado | Caras (ejemplos) |
|---|---|
| **Cliente** | cafetería · ONG ambiental · banda de música · app de salud · librería · museo |
| **Tono** | cálido · minimalista · rebelde · elegante · lúdico · nostálgico |
| **Restricción** | 2 colores · solo tipografía · una forma · blanco y negro · circular · hecho a mano |

## 2. Cómo se juega (azar + habilidad)
1. El equipo tira los tres dados → obtiene un "mini-briefing" (cliente + tono + restricción).
2. **Fase divergente (fluidez):** 5 min para bocetar **el mayor nº de conceptos** posible.
3. **Fase de decisión:** eligen uno y lo justifican según el briefing.
4. El **acierto** (justificación coherente con cliente+tono+restricción) da el puntaje, no la tirada.

## 3. Retos por nivel
### Base — Comprender
- **Consigna:** explica qué pide el mini-briefing con tus palabras.
- **R-E-A:** acierto "Tradujiste el tono a decisiones visuales concretas" · intento "¿Qué siente el cliente? eso define el tono" · pista "Empieza por el adjetivo del dado Tono".

### Reto — Crear (fluidez/flexibilidad)
- **Consigna:** genera ≥6 conceptos distintos para el mini-briefing.
- **R-E-A:** acierto "Tus ideas vienen de categorías distintas, no variaciones de una sola: eso es flexibilidad" · intento "Tienes 3 parecidas; fuerza una idea de otra categoría" · pista "Cambia el punto de partida: objeto, metáfora, palabra".
- **Creatividad:** fluidez + flexibilidad.

### Experto — Evaluar
- **Consigna:** defiende tu concepto elegido y anticipa una crítica.
- **R-E-A:** acierto "Justificaste con el briefing y te adelantaste a la crítica: madurez de criterio" · intento "Buena elección; ¿qué objetaría el cliente? respóndelo" · pista "Mira la restricción: ¿la cumples de verdad?".

## 4. Variante cooperativa
Toda la clase comparte un mini-briefing por tirada y construye un mural común de conceptos; se celebran todas las ideas aportadas.

## 5. Salvaguardas de bienestar e inclusión
- Nadie pierde por la tirada; los dados solo dan el punto de partida.
- Sin cronómetro estresante (los 5 min son orientativos y ampliables).
- Roles rotativos sorteados con un d6 → equidad de participación.
- Entrega multiformato: boceto, palabras o descripción oral.

## 6. Notas para el/la docente
- Encuadra la divergencia como práctica: aquí no hay ideas "malas".
- Usa la fase de decisión para modelar retroalimentación R-E-A.
- Evidencia de logro: nº y variedad de conceptos + calidad de la justificación.
```
