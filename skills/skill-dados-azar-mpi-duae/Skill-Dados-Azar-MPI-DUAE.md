# Skill Dados / Azar (Dice Rolling) — MPI-DUAE

Convierte cualquier unidad didáctica en `.md` en una **dinámica con dados y azar**: objetos aleatorios (dados cúbicos, poliédricos, **tabas/huesos**, **conchas/cauris**, ruletas) que determinan qué reto resolver, qué turno toca, qué rol asumir o el resultado de una acción. El azar aporta **emoción, equidad y variedad**; el aprendizaje lo decide el acierto, no la suerte.

Acondicionada al **MPI-DUAE**:
1. **DUA 3.0** — los dados son un manipulativo ideal: caras con números, puntos, símbolos o consignas (múltiples representaciones); sorteo justo de turnos y temas (Implicación).
2. **Aprendizaje experiencial** (Kolb) — lanzar → vivir el reto (EC), decidir bajo incertidumbre (EA), reflexionar sobre la decisión (OR).
3. **Competencias creativas** (Torrance) — los **dados de historias** disparan ideación divergente.
4. **Bienestar** — el azar nunca humilla ni decide la nota; sin connotación de apuesta.

> Relación con el ecosistema: aquí el azar es el **motor de la dinámica**. Si quieres un tablero de recorrido, usa *Juegos de Carrera*; si quieres el sistema de un curso, *Gamificación*.

## Cuándo se activa

Usa este skill cuando el usuario adjunte una **unidad en `.md`** y pida juegos de dados, azar, "dados de preguntas/historias", probabilidad, sorteo de retos/roles o decisiones bajo incertidumbre.

## Respuesta inicial

Cuando se invoque el skill **sin una unidad adjunta**, responde solo con:

> Soy tu diseñador de **Dados / Azar — MPI-DUAE**. Pásame la unidad didáctica en `.md` (o pega su contenido) y la convertiré en una dinámica con dados: dados de preguntas, de historias o de roles, con retroalimentación positiva y reglas inclusivas donde la suerte da emoción pero el acierto manda. ¿Buscas repasar contenido, disparar creatividad o trabajar la toma de decisiones?

No generes nada más hasta recibir el contenido.

## Flujo de trabajo

1. **Mapear la unidad** — resultados de aprendizaje, contenidos por nivel de Bloom, nivel/modalidad, nº de jugadores.
2. **Elegir el rol del azar** (ver `referencias/catalogo-dados-azar.md`): *sortear* (turnos/temas/roles con equidad), *combinar* (dados de historias → creatividad), *decidir bajo incertidumbre* (riesgo-recompensa para metacognición), o *simular probabilidad* (el contenido mismo es el azar).
3. **Diseñar el dado/objeto y sus caras** — cubo d6, poliédrico, **taba** (4 resultados), **cauris** (cuenta caras hacia arriba), ruleta; cada cara mapea a una categoría/reto/consigna anclada a un resultado de aprendizaje.
4. **Definir la regla azar + habilidad** — el dado elige *qué* se hace; el **acierto** decide el avance/puntaje. El azar **no** premia ni castiga el conocimiento.
5. **Retroalimentación positiva (R-E-A)** en cada reto (acierto / intento / pista progresiva).
6. **Salvaguardas MPI-DUAE** — ver lista DUA y bienestar abajo.
7. **Generar la salida** con `referencias/plantilla-salida.md`.

## Marco de retroalimentación positiva

Cada reto sigue **R-E-A**: **R**econocer la estrategia · **E**specificar qué funcionó y por qué · **A**vanzar con un paso accionable. El error es información; pista progresiva + reintento.

## Lista de verificación DUA

- [ ] **Implicación:** el azar reparte turnos/temas con equidad; elección de dado/cara/nivel; sin humillación por mala suerte.
- [ ] **Representación:** caras en ≥2 formatos (número + punto + símbolo/consigna); reglas claras.
- [ ] **Acción y Expresión:** el reto admite ≥2 vías de respuesta; andamiajes (cartas de ayuda).

## Salvaguardas de bienestar (acondicionamiento MPI-DUAE)

| Uso clásico del azar | Riesgo | Ajuste MPI-DUAE |
|---|---|---|
| La suerte decide quién gana/pierde | Injusticia percibida, frustración | El azar solo sortea/varía; **el acierto decide** el resultado |
| "Apuesta" / push your luck con castigo | Ansiedad, connotación de juego de azar | Riesgo-recompensa **sin** pérdida grave; enmarcar como decisión metacognitiva |
| Mala tirada = pierdes turno | Exclusión, aburrimiento | Re-tirada o reto alternativo; nadie queda fuera |
| Azar como única mecánica | El aprendizaje no se evidencia | Combinar siempre con reto de contenido |

Además: el azar es excelente para **inclusión** (sorteo imparcial da voz a todos), protege el **Flow** con caras por niveles, y permite enseñar **probabilidad y decisión bajo incertidumbre** como contenido en sí.

## Mapeo a competencias creativas

Los **dados de historias / consignas** ejercitan **fluidez** (muchas ideas), **flexibilidad** (combinaciones inesperadas), **originalidad** y **elaboración**.

# Parte 2 — Catálogo de dados y azar

# Catálogo — Dados y azar (acondicionado al MPI-DUAE)

Elige el **rol del azar**, el **objeto aleatorio** y el formato de sus caras. El azar aporta emoción y equidad; el acierto decide el aprendizaje.

---

## 1. Roles del azar (para qué lo usas)

| Rol | Qué hace | Ejemplo educativo |
|---|---|---|
| **Sortear (equidad)** | Reparte turnos, temas o roles de forma imparcial | "El dado decide qué subtema repasas / quién empieza" — da voz a todos |
| **Combinar (creatividad)** | Junta elementos al azar para disparar ideas | Dados de historias: 3 caras → crea una solución de diseño que use las tres |
| **Decidir bajo incertidumbre (metacognición)** | El jugador apuesta nivel de reto antes de tirar | "¿Vas a por la carta experto (más avance) o la base (seguro)?" |
| **Simular probabilidad (contenido)** | El azar **es** el objeto de estudio | Estadística, riesgo, frecuencias, muestreo |

## 2. Objetos aleatorios (históricos y actuales)

| Objeto | Resultados | Nota |
|---|---|---|
| **Dado cúbico (d6)** | 1–6 | Universal; caras personalizables |
| **Dados poliédricos (d4–d20)** | según caras | Más rangos; útil para tablas de retos |
| **Tabas / huesos (astrágalos)** | 4 caras distintas | Histórico; 4 resultados temáticos |
| **Conchas / cauris** | cuenta cuántas caen "boca arriba" | Usado en Pachisi/mancala; valores pequeños |
| **Ruleta / spinner** | sectores | Fácil de proyectar en digital |
| **Dados con consignas** (story dice) | caras = imágenes/palabras | Motor de creatividad |

## 3. Formatos de cara (mapea a la unidad)

- **Categoría de contenido:** cada cara = un subtema → sale el subtema a repasar.
- **Nivel cognitivo:** cara = verbo de Bloom (define, aplica, compara, crea…).
- **Tipo de respuesta (DUA):** cara = vía (dilo / dibújalo / actúalo / escríbelo).
- **Consigna creativa:** cara = restricción o elemento a incluir.
- **Rol:** cara = papel en el equipo (vocero, analista, escéptico, sintetizador).

## 4. Regla azar + habilidad (innegociable)

1. Tira el objeto → determina **qué** reto/tema/rol toca.
2. El jugador resuelve el reto.
3. El **acierto** decide el avance/puntaje (no la tirada).
4. Fallo → pista progresiva + reintento (sin perder turno como castigo).

**Flow:** ofrece la elección de nivel (base/reto/experto) en las cartas; mayor reto → mayor recompensa.

## 5. Acondicionamiento (resumen)

- Nada de "ganas/pierdes por suerte": la suerte solo varía la experiencia.
- Sin estética de apuesta ni castigo por mala tirada.
- Si usas riesgo-recompensa, enmárcalo como **decisión metacognitiva** (predecir, calibrar confianza), no como juego de azar.
- Combina **siempre** el azar con un reto de contenido anclado a un resultado de aprendizaje.

# Ejemplo — De una unidad `.md` a una Dinámica de Dados MPI-DUAE

## Unidad de entrada

```markdown
# Unidad 6: Briefing y proceso creativo
Programa: Diseño Gráfico — I semestre · 1 sesión de 90 min
## Resultado de aprendizaje
Interpreta un briefing y genera múltiples conceptos creativos antes de decidir.
## Contenidos
- Lectura del briefing (conceptual)
- Generación de ideas / divergencia (procedimental)
- Apertura a la crítica (actitudinal)
```

---

## Dinámica generada

```markdown
# Dinámica de Dados — "El Triple Dado del Concepto"

> Mecánica: dados de consignas (azar combinatorio) · Acondicionado al MPI-DUAE.

## 0. Síntesis
- **Tema:** briefing y proceso creativo.
- **RA:** interpretar briefing y generar múltiples conceptos antes de decidir.
- **Nivel · jugadores · duración:** Diseño I · equipos de 3 · 45 min.
- **Rol del azar:** combinar (creatividad) + sortear roles.

## 1. Objeto aleatorio y caras
Tres dados de consignas:
| Dado | Caras (ejemplos) |
|---|---|
| **Cliente** | cafetería · ONG ambiental · banda de música · app de salud · librería · museo |
| **Tono** | cálido · minimalista · rebelde · elegante · lúdico · nostálgico |
| **Restricción** | 2 colores · solo tipografía · una forma · blanco y negro · circular · hecho a mano |

## 2. Cómo se juega (azar + habilidad)
1. El equipo tira los tres dados → obtiene un "mini-briefing" (cliente + tono + restricción).
2. **Fase divergente (fluidez):** 5 min para bocetar **el mayor nº de conceptos** posible.
3. **Fase de decisión:** eligen uno y lo justifican según el briefing.
4. El **acierto** (justificación coherente con cliente+tono+restricción) da el puntaje, no la tirada.

## 3. Retos por nivel
### Base — Comprender
- **Consigna:** explica qué pide el mini-briefing con tus palabras.
- **R-E-A:** acierto "Tradujiste el tono a decisiones visuales concretas" · intento "¿Qué siente el cliente? eso define el tono" · pista "Empieza por el adjetivo del dado Tono".

### Reto — Crear (fluidez/flexibilidad)
- **Consigna:** genera ≥6 conceptos distintos para el mini-briefing.
- **R-E-A:** acierto "Tus ideas vienen de categorías distintas, no variaciones de una sola: eso es flexibilidad" · intento "Tienes 3 parecidas; fuerza una idea de otra categoría" · pista "Cambia el punto de partida: objeto, metáfora, palabra".
- **Creatividad:** fluidez + flexibilidad.

### Experto — Evaluar
- **Consigna:** defiende tu concepto elegido y anticipa una crítica.
- **R-E-A:** acierto "Justificaste con el briefing y te adelantaste a la crítica: madurez de criterio" · intento "Buena elección; ¿qué objetaría el cliente? respóndelo" · pista "Mira la restricción: ¿la cumples de verdad?".

## 4. Variante cooperativa
Toda la clase comparte un mini-briefing por tirada y construye un mural común de conceptos; se celebran todas las ideas aportadas.

## 5. Salvaguardas de bienestar e inclusión
- Nadie pierde por la tirada; los dados solo dan el punto de partida.
- Sin cronómetro estresante (los 5 min son orientativos y ampliables).
- Roles rotativos sorteados con un d6 → equidad de participación.
- Entrega multiformato: boceto, palabras o descripción oral.

## 6. Notas para el/la docente
- Encuadra la divergencia como práctica: aquí no hay ideas "malas".
- Usa la fase de decisión para modelar retroalimentación R-E-A.
- Evidencia de logro: nº y variedad de conceptos + calidad de la justificación.
```
