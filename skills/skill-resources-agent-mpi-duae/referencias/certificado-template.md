## Variantes
- **Reconocimiento de proceso:** destaca la mejora y la resiliencia (no el ranking).
- **Reconocimiento de aporte al grupo:** valora la colaboración y el apoyo a pares (Filántropos).
- **Reconocimiento de hito:** completar el Diario de Diseño, una iteración, una presentación.

## Reglas de calidad
- [ ] Reconoce el **proceso**, no solo el resultado.
- [ ] Datos completos (nombre, unidad, programa, fecha, firmas).
- [ ] Lenguaje inclusivo y respetuoso.
- [ ] **Sin** comparaciones humillantes ni "primer/último lugar".
- [ ] Reutilizable como base para impresión o versión digital.
