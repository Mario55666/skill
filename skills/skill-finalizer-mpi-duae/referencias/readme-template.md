## Evaluacion

### Enfoque evaluativo

Esta unidad adopta una evaluacion **diagnostica, formativa y autoevaluativa**. No hay examenes tradicionales. La evaluacion ocurre durante todo el proceso y busca:

1. **Mapear el progreso** de cada estudiante en las 4 dimensiones creativas
2. **Identificar barreras** de aprendizaje tempranamente para adaptar la ensenanza
3. **Celebrar avances** individuales sin comparacion entre pares

## Reglas de Redaccion del README

1. **Lenguaje**: Espanol neutro, accesible para docentes de cualquier especialidad. No jerga innecesaria.
2. **Longitud**: Entre 150-250 lineas renderizadas (sin contar tablas vacias). Conciso pero completo.
3. **Scaneabilidad**: Uso extensivo de tablas, listas, y negritas. El lector debe encontrar lo que busca en 10 segundos.
4. **Personalizacion**: Las secciones entre corchetes `[...]` deben ser reemplazadas por contenido especifico de la unidad. Nunca dejar un `[campo]` sin completar.
5. **Contexto peruano**: Mencionar explicitamente la conexion con el contexto peruano en al menos una seccion (Presentacion o Proyecto Integrador).
6. **MPI-DUAE visible**: El nombre del modelo pedagogico debe aparecer al menos 3 veces (ficha tecnica, evaluacion, creditos) para identidad y trazabilidad.
7. **Accesibilidad**: Siempre incluir la nota de contacto para consultas sobre adaptaciones al final del documento.
8. **Sin datos sensibles**: Nunca incluir nombres de estudiantes, notas reales, ni informacion personal en el README.
