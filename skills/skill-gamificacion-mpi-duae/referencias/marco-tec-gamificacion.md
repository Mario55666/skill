# Marco de Gamificación — Tec de Monterrey, acondicionado al MPI-DUAE

Basado en *Edu Trends: Gamificación* (Observatorio de Innovación Educativa, Tecnológico de Monterrey, 2016). Úsalo para seleccionar elementos, anticipar tipos de jugadores, estructurar el trayecto y planear la evaluación. La columna "Acondicionamiento MPI-DUAE" indica cómo cuidar inclusión y bienestar.

---

## 1. Diferencias clave (no confundir)

| Concepto | Qué es |
|---|---|
| **Gamificación** | Usar *principios y elementos* del juego para motivar el aprendizaje; **no** usar juegos en sí. |
| **Aprendizaje Basado en Juegos (GBL)** | Usar juegos existentes como medio de instrucción (Jeopardy, Serpientes y Escaleras, Angry Birds para tiro parabólico…). |
| **Juegos Serios** | Juegos diseñados con propósito educativo/informativo (simuladores, *Darfur is dying*). |

Este skill diseña **Gamificación**. Si conviene un juego completo, deriva al Skill Games (GBL).

## 2. Elementos del juego

Selecciona solo los pertinentes al objetivo. Para cada uno: qué aporta · ejemplos del elemento · **acondicionamiento MPI-DUAE**.

| Elemento | Qué aporta | Ejemplos | Acondicionamiento MPI-DUAE |
|---|---|---|---|
| **Metas y objetivos** | Dirigen el esfuerzo; dan propósito | Retos, misiones, desafíos épicos | Metas claras y alcanzables; niveles base/reto/experto (Flow) |
| **Narrativa** | Contextualiza y engancha | Avatares, personajes, mundos, escenarios | Narrativa inclusiva y diversa; permite elegir personaje |
| **Reglas** | Mantienen el juego manejable | Turnos, cómo ganar/perder, condiciones | Sencillas, claras, **no cambiarlas a mitad del juego** |
| **Libertad de elegir** | Autonomía y exploración | Rutas, casillas, poderes, recursos | Clave para DUA (Implicación + Acción/Expresión) |
| **Libertad para equivocarse** | Confianza para arriesgar | Vidas múltiples, reinicios, intentos ilimitados | **Innegociable**: el error es información, sin castigo |
| **Progreso (andamiaje)** | Avance gradual de dificultad | Tutoriales, puntos de experiencia, niveles, barras | Equilibrio reto-habilidad (Flow); andamiaje real |
| **Recompensas** | Sensación de logro | Monedas, vidas, ítems, poderes | Orientar a **motivación intrínseca** (dominio), no solo premio |
| **Estatus visible** | Reconocer avance propio y ajeno | Insignias, puntos, logros, tablero | Mostrar **mejora personal/equipo**, no humillar a los últimos |
| **Retroalimentación** | Guía el avance | Pistas visuales, barras, señales correcto/incorrecto | Inmediata + **R-E-A**; pistas progresivas antes que la respuesta |
| **Cooperación y competencia** | Motiva por reto social | Equipos, gremios, batallas, tablero | **Priorizar cooperación**; competencia sana por equipos |
| **Sorpresa** | Mantiene el interés | Recompensas aleatorias, *easter eggs*, eventos | Positiva, nunca castigo sorpresa ni estrés |
| **Restricción de tiempo** | Presión para concretar | Cuenta regresiva, beneficios temporales | **Opcional/ajustable**; nunca única vía (ansiedad, exclusión) |

## 3. Tipos de jugadores (motivaciones)

Diseña para varios a la vez (DUA-Implicación). Síntesis de Bartle, Quantic Foundry y Marczewski.

| Tipo | Motivación | Qué le engancha | Diséñale… |
|---|---|---|---|
| **Exploradores** | Descubrir | Ver posibilidades, probar, fantasía/narrativa | Rutas abiertas, secretos, mundo rico |
| **Pensadores** | Resolver | Acertijos, retos creativos, encontrar "la respuesta" | Problemas con varias soluciones |
| **Triunfadores** | Logro y dominio | Ganar, completar todo, puntos | Niveles, retos escalables, metas claras |
| **Socializadores** | Relación | Colaborar, conversar, conocer pares | Equipos, roles, espacios de interacción |
| **Filántropos** | Propósito/significado | Ayudar a otros sin recompensa | Roles de mentor/apoyo, metas comunes |
| **Revolucionarios** | Cambio | Retar el sistema, hacer lo inesperado | Retos abiertos, espacio para proponer reglas |

**Regla:** si solo diseñas para Triunfadores (puntos y rankings), pierdes a la mayoría del grupo.

## 4. Trayecto del jugador (≡ ciclo de Kolb)

| Etapa (Tec) | Qué hace el profesor | Fase Kolb |
|---|---|---|
| **Descubrimiento** | Presenta reglas, componentes, mecánicas, narrativa | (encuadre) |
| **Entrenamiento / Onboarding** | Reto sencillo, primeros logros, "tutorial" | **Experiencia Concreta** |
| **Andamiaje / Scaffolding** | Guía + retroalimentación; equilibrio reto-habilidad (**Flow**, Csíkszentmihályi) | **Observación Reflexiva → Conceptualización** |
| **Hacia el dominio** | Nuevas habilidades, progreso gradual ligado al diseño instruccional | **Experimentación Activa** |

## 5. Tabla: elemento del juego → competencia que evidencia (evaluación)

| Elemento | Evidencia / competencia |
|---|---|
| Retos, misiones, desafíos | Aplicar conocimientos; realizar tareas específicas |
| Narrativa | Contenido declarativo; asociar conceptos/ideas/hechos |
| Reglas y restricciones | Actitudes: respeto, honestidad |
| Elegir entre rutas | Toma de decisiones, resolución de problemas, creatividad |
| Múltiples intentos / vidas | Resiliencia, tolerancia a la frustración |
| Equipos, roles, batallas | Trabajo colaborativo, liderazgo, decisiones |
| Puntos de experiencia, niveles, barras | Progreso hacia objetivos; adquisición/aplicación de conocimiento |
| Insignias, niveles, logros | Adquisición de habilidades, dominio de conocimientos |
| Cuenta regresiva | Eficiencia de procesos, optimización, decisiones bajo presión |

**Evaluación discreta (stealth assessment):** infiere el dominio a partir de la secuencia de acciones del jugador, sin interrumpir el juego. Si la dinámica no da evidencia suficiente, complementa con evaluación posterior y **co-evaluación** entre pares.

## 6. Recursos y herramientas (sugerir según contexto)

- **Diseñar la estrategia:** Lienzo de Gamificación.
- **Gestionar la actividad:** ClassCraft, Rezzly (antes 3DGameLab).
- **Respuestas rápidas / quizzes:** Socrative, Kahoot!, FlipQuiz, JeopardyLabs.
- **Insignias / certificación:** BadgeMaker, ClassBadges, Mozilla Open Badges.
- **Actividades en tableta:** BookWidgets.

No exijas tecnología que el contexto no tenga: muchos elementos funcionan con tablero físico, hoja de cálculo y proyector.

---

## 7. Mirada crítica (recordatorio del Tec)

- La gamificación **no asegura el aprendizaje** ni rescata un mal diseño instruccional.
- **No basta** con puntos/insignias/niveles: debe generar una dinámica significativa.
- **Consume tiempo**; no es receta universal.
- La evidencia científica aún es limitada → define qué medirás.
